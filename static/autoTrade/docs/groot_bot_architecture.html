Composite Scoring Engine

The tool's core idea: six independent lenses on the market are each scored, then summed per-instrument (computeInstrumentScore) and rolled up into weighted component scores for the two indices. There is no single global SCORE variable outside setScore() — it's always the sum of the globals below.

  subgraph S1["9:15 Opening Candle"]
    A1["ALL_9_15_CLOSE_SCORE
weighted bullish/bearish ratio"]
    A2["Per-instrument ±2
NIFTY_50 · NIFTY_BANK · GIFT · SENSEX · RELIANCE · HDFCBANK"]
  end
  subgraph S2["Advance / Decline"]
    B1["ALL / NIFTY_50 / NIFTY_BANK
_ADVANCE_DECLINE_SCORE (±1)"]
  end
  subgraph S3["Futures Trend"]
    C1["getFuturesTrendScore(remark)
LONG=+1 SHORT=-1
LONG_UNWINDING=-1 SHORT_COVERING=+1"]
  end
  subgraph S4["OI / OBV"]
    D1["scoreOIStrikeForSignal() per strike
OBV-primary, IV=confidence only"]
    D2["computeOIScoreFromData()
sum + change-PCR only
(wall bonus + standing PCR removed v26.31)"]
  end
  subgraph S5["Max Pain"]
    E1["_gtbMaxPainScore(name)

  end
  subgraph S6["IV Skew"]
    F1["_gtbIVSkewScore(name)

  end
  S1 & S2 & S3 & S4 & S5 & S6 --> COMP["computeInstrumentScore(name)

  SETSCORE --> GAUGE["Gauge color thresholds
red<0 · orange 0–4 · yellow 4–8 · green≥8"]
  SETSCORE --> SIGNAL["→ Market Signal (§4)"]

Market Signal, Trade & Exit Logic

Composite SCORE plus conflict checks (index futures disagreement, 9:15 pattern mismatch, VIX regime) resolve to one plain-English signal, an entry confluence check, SL/target math, and a live exit-condition monitor.

flowchart TD
  SCORE["SCORE + breakOutNineFifteen"] --> GMS["getMarketSignal(SCORE, b915)"]
  GMS --> THRESH["Thresholds (v26.31, symmetric):
STRONG BUY≥8 · BUY≥4 · WAIT≥1.5
SIDEWAYS≥-1.5 · WAIT≥-4 · SELL≥-8 · STRONG SELL below"]
  GMS --> OVERRIDE["Conflict overrides →WAIT:
score bullish but both futures bearish (>±4)
signal vs 9:15 pattern mismatch
VIX at VIXU/VIXL → NO TRADE"]
  OVERRIDE --> CONF["getEntryConfluence(SCORE)"]
  CONF --> ATR["computeATR(candles)"]
  ATR --> SLT["computeSLAndTarget(entry, dir, candles)"]
  SLT --> TRADESIG["getTradeSignal(nifty, sensex, bank)"]
  SCORE --> EXIT["checkExitSignal(entryDirection)
— polled every tick"]
  EXIT --> EXITCOND["EXIT LONG: current_trend<0 OR both futures<0
EXIT SHORT: current_trend>0 OR both futures>0"]
  EXITCOND --> BANNER["renderExitBanner()
#gtb-exit-signal"]
  GMS --> CHECKLIST["_gtbShowTradeChecklist()
7-step checklist + action table"]
  GMS --> VERDICT["_cmdBuildVerdict() (commodities)
OVX gate → bias → wall proximity → Max Pain context
→ LONG/SHORT/WAIT/NO-TRADE + Entry/SL/Target"]

OI/OBV Analysis Pipeline

The most heavily-iterated subsystem this session: per-strike CE/PE classification, ITM/OTM-aware wall ranking, and one shared visual language (solid=opening flow, faded=closing flow, dimmed=ITM, R1/R2 & S1/S2 = tiered support/resistance) reused across every rendering surface.

Resistance (R1 solid / R2 dashed) Support (S1 solid / S2 dashed) ITM = dimmed, lower conviction
